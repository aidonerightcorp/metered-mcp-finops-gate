1. Live In-Browser WebAssembly.instantiate IEEE-754 Cartridge Lab

This interactive assembler builds a valid WebAssembly v1 binary module in browser memory from float32 weight matrices. It emits exact IEEE-754 little-endian constants, f32.load, f32.mul, f32.add, f32.max, and f32.store opcodes. Adjust any input slider or switch the cartridge preset to recompile and execute live inside your browser VM.

  1. Select a compiled weight cartridge preset from the dropdown menu.
  2. Move the four float32 input sliders to test custom feature vectors.
  3. Click Compile & Run Browser .wasm to execute native WebAssembly bytecode.
  4. Click Download .wasm Cartridge to save the generated binary module locally.
