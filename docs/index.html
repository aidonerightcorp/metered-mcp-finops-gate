Whole-Model Weight Edits vs. Weight-Space Programming on Atomic Task Graphs

Sparse weight edits on monolithic benchmarks do not increase accuracy above the unedited thinking=off baseline (51.60% ± 3.11% vs 51.84% ± 3.31% across 5 seeds). We decompose workflows into check-gated atomic task graphs with effective rank r_eff = 3.0. We then compile symbolic invariant skeletons and project residuals into the orthogonal SVD nullspace. This pipeline reaches 98.96% ± 0.25% atomic accuracy (+47.36 pp above thinking=off) with 256-byte adapters and 20.14x bundle throughput.
